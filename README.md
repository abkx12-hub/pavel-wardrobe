# Гардероб Павла

Публичная версия для просмотра супругой и стилистом. Без входа и редактирования.
Включает готовые образы, вещи, погоду и аналитику текущей версии гардероба.

Фотографии лежат в `assets` и загружаются по мере просмотра.
Отдельная локальная версия со встроенными фото сохранена для пересылки без интернета.
Виртуальные примерки — иллюстрации сочетаний,
не гарантия точной посадки вещей. Температурные подсказки учитывают личный опыт.

Публикация: GitHub Pages, ветка `main`, корень репозитория.
Поисковикам передан запрет на индексацию, но это не закрытый доступ:
содержимое доступно любому обладателю ссылки, а исходный репозиторий публичный.

Обновление: подготовить `wardrobe-web.html` из актуального локального гардероба,
запустить `node prepare-public.mjs ПУТЬ_К_ФАЙЛУ`, проверить фотографии
и отправить изменения в `main`.
Другие сайты и домены не затрагиваются. Автоматической синхронизации с локальным
гардеробом нет: публикация обновляется отдельным действием.
